September 23, 2026

**Scope of the Project:**
**1. Build a system to monitor:**
-1.1 News around Emerging Markets (Ranked by priorities for what is in our portfolios)
-1.2 Events tracking for focused companies incl. those in watchlist
-1.3 Global macro trends affecting EM

**2. Logistics Infrastructure**
-2.1 Weekly/ Daily news sent via emails.
-2.2 Report of performance on daily basis: FactSet via Playwright or we use Yahoo Finance API or a custom built scraper/ screener.
-2.3 Short portfolio analysis as well as a writeup on how news/ trends may affect our project

**3. Exploring the New Frontier**
-3.1 Build a system to automate the portfolio reports on monthly basis to be published on BSEMC channel.
-3.2 Build a market universe of stocks within certain emerging markets, starting from focused/ preferred ones then expanding to possibly match MSCI EM one day.
